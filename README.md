## How to use

Install the Morphe manager from [their website](https://morphe.software/), then add this repository as a patch source:

`https://github.com/sandy5544/InstaPatch`

## Supported Instagram version

- Instagram `439.0.0.37.89`

## Patch included

**Disable DM pull-to-refresh** disables the pull-to-refresh gesture in Instagram Direct Messages only. Feed, Reels, and other Instagram refresh behavior are not intentionally modified.
